## 四层记忆引擎

Memory Engine 是 DeepSpace 的核心，实现了四层记忆模型：

### 短期记忆 (Short-term)
- 当前会话中产生的新信息
- 自动分类和重要性评估
- 高重要性自动晋升

### 工作记忆 (Working)
- 活跃项目的上下文
- 中间状态的工作信息
- 稳定后可晋升为长期记忆

### 长期记忆 (Long-term)
- 永久保存的高价值知识
- 经过验证和多次访问确认
- 永远不会自动删除

### 元记忆 (Meta)
- 关于"我们知道什么"的知识
- 知识空白识别
- 学习方向推荐

### 混合检索

DeepSpace 使用向量搜索 + 关键词搜索的混合策略：

1. **向量搜索**：生成查询的 embedding，在 pgvector 中做余弦相似度匹配
2. **关键词搜索**：PostgreSQL 全文搜索，匹配精确术语
3. **结果合并**：去重后按重要性排序

## 知识图谱

### 实体类型

| 类型 | 说明 | 示例 |
|------|------|------|
| Project | 项目 | TimeMap, Hermes Agent |
| Concept | 概念 | RAG, 向量数据库 |

| Person | 人物 | 作者、贡献者 |

| File | 文件 | 关键配置文件 |
| Command | 命令 | CLI 命令 |
| Idea | 想法 | 创意和灵感 |

### 关系类型

| 关系 | 说明 |
|------|------|
| USES | A 使用 B |
| RELATED_TO | A 与 B 相关 |
| SOLVED_BY | 问题A 由 B解决 |
| DEPENDS_ON | A 依赖 B |
| PART_OF | A 是 B 的一部分 |
| SIMILAR_TO | A 与 B 相似 |
| LEARNED_FROM | A 从 B 学到 |
| INSPIRED | A 受 B 启发 |
| EVOLVED_INTO | A 演化为 B |

## Agent 编排器

Orchestrator 协调 7 个专业 Agent：

| Agent | 职责 |
|-------|------|
| Executive | 协调所有 Agent，决定优先级 |
| Research | 搜索和收集信息 |
| Memory | 管理记忆的存储和检索 |
| Graph | 维护知识图谱的完整性 |
| Planning | 任务分解和计划制定 |
| Reflection | 元认知分析 |
| Proactive | 上下文监控和主动推送 |

## 主动服务

Proactive Service 负责：

1. **上下文检测**：分析用户当前正在做什么
2. **需求预判**：预测用户接下来可能需要什么
3. **智能推送**：在合适时机推送相关信息
4. **每日简报**：生成每日工作总结和建议
